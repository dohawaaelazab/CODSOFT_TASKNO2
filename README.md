# Task 2: Simple Calculator (Python & Tkinter)

A graphical calculator application built using Python and Tkinter to perform standard arithmetic operations.

## Features
- **Basic Operations**: Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Real-Time Input**: Clean button grid layout for quick mathematical entry.
- **Error Handling**: Displays an "Error" notification for invalid expressions (e.g., division by zero).
- **Clear Option**: One-click clear (`C`) button to reset the calculation.

## Prerequisites
- Python 3.x
- `tkinter` (included with standard Python installations)

## How to Run
```bash
python calculator.py
